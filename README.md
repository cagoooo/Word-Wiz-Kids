## ✨ 專案核心亮點 (Features)

- 🎨 **生動活潑的視覺設計**：精美的卡片與流暢動畫，提升兒童學習專注度。
- 📚 **多元單字題庫**：包含常用生活英文、基礎單字與拼字互動練習。
- 📱 **響應式跨裝置支援 (RWD)**：無論是平板、手機還是電腦，均能獲得最佳瀏覽體驗。
- ⚡ **極速載入與順暢互動**：使用 Vite 與 React 打造，提供毫秒級反應體驗。

---

## 🛠️ 技術架構 (Tech Stack)

- **前端框架**：React 18 + TypeScript
- **建置工具**：Vite 6
- **UI 樣式與元件**：Tailwind CSS v4 + Radix UI + Lucide Icons
- **套件管理**：pnpm workspace
- **自動化部署**：GitHub Actions + GitHub Pages

---

## 🚀 本地開發指南 (Local Development)

```bash
# 1. 複製專案
git clone https://github.com/cagoooo/Word-Wiz-Kids.git
cd Word-Wiz-Kids

# 2. 安裝依賴套件
pnpm install

# 3. 啟動開發伺服器
pnpm --filter ./artifacts/vocab-kids dev
```
