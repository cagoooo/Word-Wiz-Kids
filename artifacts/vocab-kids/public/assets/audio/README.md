# 遊戲音訊素材

本目錄沿用已完成稽核的本機遊戲素材，不需要再次登入 Suno 或重新下載。

- `bgm-learn.mp3`：學習與複習，明亮、好奇且保留 TTS 空間。
- `bgm-game.mp3`：單人遊戲，活潑的兒童 8-bit 挑戰節奏。
- `bgm-arena.mp3`：全班對戰，節奏較強但不黑暗、不具攻擊性。
- `sfx-complete.mp3`：完成挑戰時的 Suno 勝利短曲。
- 其餘短音效來自既有專案的 Pixabay Content License 素材。

所有檔案已轉為瀏覽器相容的 MP3，來源、授權、Suno Clip ID 與 SHA-256 記錄於
`audio-manifest.json`。執行時若短音效無法解碼，程式會自動改用 Web Audio 合成音。
